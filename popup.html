How to Use

Quickly insert saved text using short aliases

Getting Started

  1. Login to the main website.
    Main website: ( Link)
  2. Insert the DATA and ALIAS pair on the main website and save it

Using an Alias

  • Enable the extension to avail the functionality
  • Type the respective alias_name where you want the saved data with a leading identifier (RBS.alias_name)
  • Trigger the extension by inserting a space after typing the alias name
  • The alias will then be replaced by the actual data stored on the server

Alias Not Found

You'll see "RBS_INVALID.alias_name" if the alias does not exist.

Important Notes

  • Aliases must be unique
  • Aliases are case-sensitive
  • Extra spaces (leading or trailing) are ignored
  • Login is required

Tip

Use short aliases like name, add (for address), Intro, aboutme.

Usage Notice!!!

RBS works best on standard text inputs such as input and textarea.

Some modern websites (like chat apps and rich editors) use custom contenteditable elements. In these cases, alias detection and expansion may be delayed or inconsistent.

RBS will not work in browser-restricted areas such as the address bar, or system dialogs.

Tip: For the most reliable experience, use RBS in simple text fields and avoid relying on it for critical messages in complex editors.
